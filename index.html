        ♯ F♯ → C♯ → G♯ → D♯ → A♯ → E♯ → B♯　/　♭ B♭ → E♭ → A♭ → D♭ → G♭ → C♭ → F♭

        도·레·미는 고정된 음이름이에요. E♯는 F, B♯는 C, C♭는 B, F♭는 E와 같은 건반을 눌러요. 아래 음계는 상행 순서이며, 항목을 누르면 따라 치기에 불러와요.
